## **Rate Select** 

The signaling rates for the transmitter and receiver can each be configured by either the rate select (RS) hard pin signals or the soft register bits according to the following table: 

|**Fibre Channel**<br>**Rate**|**Signaling Rate**<br>**(GBd)**|**Modulation**|**Logic OR of**<br>**RS hard**<br>**pin and**<br>**soft bit**|**A2h, Byte**<br>**119, Bit 2**<br>**(64GFC**<br>**Mode bit)**|**Notes**|
|---|---|---|---|---|---|
|64GFC|28.9|PAM4|-|1|When the 64GFC Mode bit is set,<br>the RSpins and bits are ignored.|
|32GFC|28.05|NRZ|1|0||
|16GFC|14.025|NRZ|0|0||



## **Monitor Data** 

The following monitors are supported using the “internal calibration” method described in SFF-8472 Rev 12.3: 

- Temperature 

- Supply Voltage 

- Tx Bias Current 

- Rx Optical Power 

- Tx optical power 

## **Alarm / Warning Flags** 

All alarm and warning flag bits are latched and are clear-on-read registers.

## TS5001-M85C-SO 

The TS5001-M85C-SO is an SFP+ form-factor transceiver for 50Gbps Ethernet applications. Since the transmission rate can reach up to 56Gbps, the engineering and industry name is SFP56. It is intended for use in inter- and intra-connect applications within data centers between switches, routers, storage equipment etc. The optical performance is in accordance with the IEEE 50GBASE-SR standard, i.e. for optical distances up to 100m over a MultiMode (MM) OM4-grade fiber. 

TS5001-M85C-SO uses a single 850nm channel @ 53.125 Gbps to transport a 50G Ethernet signal. Digital diagnostics functions are available via an I2C interface, as specified by the MSA. 

As stipulated by the 50G Ethernet standards, Forward Error Correction (FEC) is required to be implemented by the host to ensure reliable system operation. The optical parameters below will provide a bit error ratio (BER) of 2.4 x 10[-4 ] for 50G Ethernet. FEC will provide the required quality for secure service.

## **LQD-DM31800XDR8C** 800G QSFP-DD XDR8 1310nm 2km Dual MPO-12/APC DOM Transceiver 

## **Product Features** 

- Compliant with IEEE 802.3cu-2021: - 8x100GBASE-FR1 optical interface 

- Compliant with IEEE 802.3ck-2022: - 8x100GAUI-1 C2M electrical interface 

- Compliant with QSFP-DD MSA HW Rev 7.0 type 2B with Dual MPO-12 connector 

- Compliant with CMIS Rev 5.0 

- Two wire serial Interface with digital diagnostic monitoring 

- Case Temperature Range: 0 ~ +70℃ 

- Class 1 Laser 

- Built-in Broadcom 7nm DSP Chip 

- Maximum Power Consumption 18W 

- Dual-interface design enables flexible 2x 400G or 8x 100G Breakout networking 

## **Applications** 

- 800G Ethernet 

- Data Centres 

- Breakout 2x 400G XDR4 or 8x 100G FR 

## **Description** 

The LQD-DM31800XDR8C QSFP-DD Optical Transceiver Module is designed for 800GBASE Ethernet throughput up to 2km over eight pairs of singlemode fiber (SMF) with Dual MPO-12/APC connectors. This transceiver is compliant with IEEE P802.3ck, IEEE 802.3cu, QSFP-DD MSA. This module has 2x MPO-12 connectors, enabling 2 physically distinct 400G-XDR4 links from each 800G transceiver without the need for optical breakout cables. It's suitable for 800G Ethernet, Data Center, Breakout 2x 400G XDR4 or 8x 100G FR applications.

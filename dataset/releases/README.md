# Curated Releases

Place reviewed snapshots in a version directory, for example `v1.0.0/`. Do not move
working extraction runs here or overwrite an already published version.

Before publishing a snapshot:

- Select and document dataset licensing and third-party exclusions.
- Validate records and document missing-value conventions, units and schema version.
- Define duplicate handling and the module/mode counting methodology.
- Review source attribution and remove private/local paths from release exports.
- Audit included text and reports for vendor redistribution restrictions.
- Include JSON/CSV exports, a manifest, checksums and the generating configuration.
- Record dataset version, date, software revision, lexicon version and environment.
- Provide citation metadata and evaluation methodology for any accuracy claims.

No curated snapshot was generated by the repository reorganization. Existing exporters
write to `workspace/` by default so review can happen before publication.

## **Data Sheet** ## **AFBR-5972EZ** **Compact 650-nm Transceiver with Compact Versatile-Link Connector for Fast Ethernet and up to 250 Mbaud over POF** ## **Description** The Broadcom[®] AFBR-5972EZ transceiver provides the system designer with the ability to implement Fast Ethernet (100 Mb/s) over standard bandwidth 0.5 ± 0.05 NA POF. This transceiver features a compact Versatile-Link duplex connector that is compatible with existing Versatile-Link simplex connectors, and it features a very compact design with a form factor similar to a UTP connector. The AFBR-5972EZ transceiver is lead-free and compliant with RoHS. ## **Features** - Fast Ethernet communications over POF - Link lengths up to 50m POF (NA 0.5) or 70m POF (NA 0.3) - Compact footprint - 3.3V operation - Data rates up to 250 Mbaud - LVDS input and output data connections - Analog RSSI (receiver signal strength) monitor output - Temperature range –40°C to 85°C ## **Figure 1: Block Diagram** **----- Start of picture text -----**<br> Differential<br>Data Output<br>Integrated<br>Receiver<br>Integrated<br>RSSI Output Photodiode<br>LED<br>Driver<br>Differential<br>Data Input<br>LED<br>**----- End of picture text -----**<br> ## **Applications** - Factory automation at Fast Ethernet speeds - Fast Ethernet networking over POF - Proprietary communication over POF up to 250 Mbaud AV02-4953EN December 2, 2025 Broadcom Compact 650-nm Transceiver with Compact Versatile-Link Connector for Fast Ethernet and up to 250 Mbaud over POF **AFBR-5972EZ** Data Sheet ## **Transmitter** The transmitter contains a 650-nm LED with a driver IC.

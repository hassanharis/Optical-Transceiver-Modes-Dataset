Notes
QSFP-DD type 2a. Nominal wavelengths stated as 191.3–196.1 THz (tunable) with 6.25 GHz grid; wavelengths in nm not printed. Operating temperature +15°C to +75°C; footnote: module turns up from cold start at ambient as low as -5°C and reaches spec after self-heating to min temperature. Storage -40°C to +85°C. OIF 400ZR Application Mode 2 (app code 0x02) is un-amplified. OpenZR+ defined for amplified line systems only. Enhanced mode grants better optical performance but is not fully interoperable with OpenZR+. Tx/Rx powers are average power. Host can attenuate Tx up to 10 dB from max available (OpenZR+ footnote). OpenZR+ Rx @ OSNR column: Min OSNR @ min Rx power for that OSNR value. CDC range column: CD range with less than 0.5 dB OSNR penalty. OIF 400ZR input power range 0 to -12 dBm (app code 0x01); receiver sensitivity -20 dBm (app code 0x02). Absolute max: Rx signal input +13 dBm, Rx total input +15 dBm.

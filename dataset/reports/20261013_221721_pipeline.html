DATASHEET 6.0 ## **SFP28 ZR 80km** ## SFP28, 25G Ethernet ZR, 1300nm, SM, 80km, 30dB, LC, C-temp, I-temp ## TS2014-S30x-SO The TS2014-S30x-SO is an SFP+ form-factor transceiver for 25Gbps Ethernet applications. It is intended for use in interconnect applications between data centers with switches, routers, storage equipment etc. The optical performance supports distances up to 80km over a SingleMode (SM) fiber. TS2014-S30x-SO uses a single 1300nm channel to transport a 25G Ethernet signal. As stipulated by the 25G Ethernet standards, Forward Error Correction (FEC) is required to be implemented by the host equipment to ensure reliable system operation. The optical parameters below will provide a bit error ratio (BER) of 5 x 10[-5 ] for 25G Ethernet. FEC will provide the required quality for secure service. The electrical interface is according to 25GAUI specifications per IEEE 802.3cc. TS2014-S30x-SO is provided in a C-temp version (TS2014-S30C-SO) and an I-temp version (TS2014-S30I-SO).

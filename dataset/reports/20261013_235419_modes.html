Features also list Commercial case 0 to +70°C and Industrial -40 to +85°C for the family. Electrical Power Interface text states +5V +/- 5% input range and that 3.3V max is not allowed for continuous operation, while Table 1 specifies +3.3V electrical power interface (Vcc 3.13–3.47 V).

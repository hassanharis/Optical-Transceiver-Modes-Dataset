DATASHEET 6.1 ## **QSFP-DD 400GBASE-ER4 LITE, CMIS4.0** QSFP-DD 400G-ER4 Lite Ethernet, PAM4 CMIS4.0, 1296/1300/1305/1309nm, 30km 15.5dB ## TQD023-SL4C-SO The TQD023-SL4C-SO is a QSFP-DD form-factor transceivers for 400Gbps Ethernet applications. The intended use is data center interconnect for optical distances up to 30km over a SingleMode (SM) fiber cable. The electrical interface consists of eight 53.125G signals (400GAUI-8) that are converted to four PAM4-modulated channels/lanes to transport the Ethernet signal. The transceiver can also be set in 4x100GAUI-2 mode to enable 400G to 4x 100G break-out configurations. Digital diagnostics functions are available via an I2C interface, as specified by the QSFP-DD MSA. Forward Error Correction (FEC) is required to be implemented by the host in order to ensure reliable system operation. The FEC type shall be as defined in IEEE802.3bj, i.e. Reed Solomon RS(528,514). The optical parameters will provide a bit error ratio (BER) of 2.4 x 10-4. TQD023-SL4C-SO also allows an onboard FEC, P-FEC, through application code 3 to allow better performance. The TQD023-SL4C-SO is compliant with Common Management Interface Specification CMIS4.0. ## TECHNICAL DATA |**Parameter**||**Value**||**Parameter**|**Value**| |---|---|---|---|---|---| |Technology||Grey QSFP-DD||**Transmitter data:**|| |Transmission media||SM (2xLC)||Output power, per lane|Min: +0.4dBm3)| |Typical reach||30km|||Max: +6.5dBm| |Nominal wavelength||1296/1300/1305/1309nm||Output power, OMA, per lane|Min: +3.4dBm| |Interface standards||400G ER4 Lite|||Max: +9.0dBm| |Electrical interfaces||400GAUI-8 or 4x100GAUI-2||ER|Min: 6dB| |Bit rate support||425Gbps1)||Transmit wavelengths|1294.53 – 1296.59nm| |||53.125Gbd2)|||1299.02 – 1301.09nm| |Protocol support||400GbE, 4x100GbE|||1303.54 – 1305.63nm| |Power budget||3.8 – 15.5dB|||1308.09 – 1310.19nm| |Power consumption||< 12W||**Receiver data:**|| |Operating temperature||0°C to +70°C||Receiver sensitivity, OMA, ...

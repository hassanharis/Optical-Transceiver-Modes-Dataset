DATASHEET 5.2 ## **SO-QSFP-DD-4C-FR4-4-M** QSFP-DD 400G-FR4 Ethernet, 4x100G-FR, PAM4 CMIS4.0, 4x1311nm, 2km, 4dB, MPO ## OVERVIEW The SO-QSFP-DD-4C-FR4 is a QSFP-DD form-factor transceiver for 400Gbps Ethernet applications. It is intended for use in data center interconnect between switches, routers, storage equipment etc. for optical distances up to 2km over a SingleMode (SM) ribbon fiber cable. The electrical interface consists of eight 53.125G signals (400GAUI-8) that are converted to eight PAM4-modulated channels/lanes to transport the Ethernet signal. The transceiver can also be set in 4x100GAUI-2 mode to enable 400G to 4x 100G break-out configurations. Digital diagnostics functions are available via an I[2] C interface, as specified by the QSFP-DD MSA. The optical interface to the transceiver is an MPO12 connector. Forward Error Correction (FEC) is required to be implemented by the host to ensure reliable system operation. The FEC type shall be as defined in IEEE802.3bj, i.e. Reed Solomon RS(528,514).

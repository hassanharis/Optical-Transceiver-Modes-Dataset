Notes
The module is described as DWDM, coherent tunable C-band, QSFP-DD type 2a, SM (2x LC). Rx sensitivity is specified at OSNR > 36dB. The unpenalized Rx OSNR value is 15.5dB at -20dBm. CDC range is 8 600 ps/nm at 0.5dB OSNR penalty. Maximum available TX power is somewhere in the range -5.0 to 0dBm and can be provisioned up to 10dB below that maximum; the default is the maximum available power. Rx overload values are 13dBm signal power and 15dBm total power; the damage threshold is 16dBm. The overload specification applies within the pre-FEC BER range of the selected application code. Storage temperature is -40°C to +85°C.

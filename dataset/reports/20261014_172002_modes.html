Notes
Module is a QSFP-DD type 2a DWDM coherent tunable transceiver (100G Ethernet/OTN/OpenROADM), CMIS 5.0, AES-256 encryption via I2C (supported for application codes 4-7 only). Reach: 130km unamplified, 450km dispersion limited (amplified links). Tx power: maximum available Tx power lies somewhere in the range -5.0 to 0dBm; can be provisioned up to 10dB below the maximum (Transmit VOA dynamic range 0 - 10dB); defaults to the maximum if not provisioned by host. Tx wavelengths 191.275 - 196.125THz in minimum 6.25GHz steps. Rx sensitivity -32dBm (application codes 1-7, oFEC) and -30dBm (application codes 8-11, SC-FEC), specified at OSNR > 36dB. Rx OSNR 15.5dB specified at -20dBm Rx power (identical for all application codes). Rx overload: signal power 13dBm, total power 15dBm, specified to be within the pre-FEC BER range of the selected application code; Rx damage threshold 16dBm. CDC limit 8600ps/nm (8 600 ps/nm, CDC range @0.5dB OSNR penalty). oFEC: NCG 11.6dB at pre-FEC BER 2.0x10^-2 (OpenZR+ 100G option, OpenROADM 3.0/4.0). SC-FEC: NCG 9.4dB at pre-FEC BER 4.5x10^-3 (OpenROADM 2.0, OTU4 media format). Baud rates: 30.1Gbd (OpenZR+, codes 1-3), 31.6Gbd (FlexO-1, codes 4-7), 28.0Gbd (OTU4, codes 8-11). Modulation DP-QPSK for oFEC codes, DP-DQPSK for SC-FEC codes. Latency: oFEC 11us (13.5us with encryption), SC-FEC 20us (22.5us with encryption). Wavelength switch time max 86s channel to channel. Tx In-Band OSNR min 34dB/0.1nm; Tx Out-Of-Band OSNR min 30dB/0.1nm. Operating temperature 0°C to +75°C; storage temperature -40°C to +85°C. Power consumption 17.0W (Class 8). Features: DDM, SyncE. Regulatory: TUV/UL/FDA, RoHS. Wavelength in nm not stated (only THz frequency range). Media format names (OpenZR+, FlexO-1, OTU4) are listed under 'Media Format' column.
